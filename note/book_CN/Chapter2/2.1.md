# 第 2 章：用数据构建 abstraction

## 2.1 引言

第 1 章中，我们关注的是计算过程，以及 function 在程序设计中的作用。我们看到了如何使用 primitive 数据（数字）和 primitive 操作（算术），如何通过组合与控制形成复合 function，以及如何通过为过程命名来创建 functional abstraction。我们还看到，higher-order function 增强了语言的能力，使我们能够以通用的计算方法来操作、并据此进行推理。这在很大程度上就是编程的精髓。

本章关注数据。我们在这里研究的技术，将使我们能够表示和操作关于许多不同领域的信息。由于互联网的爆炸式增长，海量的结构化信息在网上免费提供给所有人，计算可以应用于极其广泛的各种不同问题。有效使用内置数据类型和用户自定义数据类型，是数据处理类应用的基础。

### 2.1.1 原生数据类型

Python 中的每个值都有一个 *class*，它决定了这个值属于什么类型。共享同一个 class 的值也共享行为。例如，整数 `1` 和 `2` 都是 `int` class 的 instance。这两个值可以被类似地对待。例如，它们都可以被取负，或者与另一个整数相加。内置的 `type` function 使我们能够查看任意值的 class。

```python
>>> type(2)
<class 'int'>
```

我们目前用到的值，都是内置于 Python 语言之中的少数几种 *native* 数据类型的 instance。原生数据类型具有以下性质：

1. 有一些 expression 会求值为原生类型的值，它们被称为 *literal*。
2. 有一些内置的 function 和 operator 用来操作原生类型的值。

`int` class 是用来表示整数的原生数据类型。整数 literal（相邻数字构成的序列）求值为 `int` 值，数学 operator 则操作这些值。

```python
>>> 12 + 3000000000000000000000000
3000000000000000000000012
```

Python 包含三种原生数值类型：整数（`int`）、实数（`float`）和复数（`complex`）。

```python
>>> type(1.5)
<class 'float'>
>>> type(1+1j)
<class 'complex'>
```

**浮点数。** `float` 这个名字来自实数在 Python 以及许多其他编程语言中的表示方式：一种“浮点”表示法。数字究竟如何表示并不是本书讨论的主题，但 `int` 对象与 `float` 对象之间的一些高层差异却值得了解。特别是，`int` 对象精确地表示整数，没有任何近似，也不限制大小。另一方面，`float` 对象能够表示范围很广的小数，但并非所有数字都能被精确表示，而且存在最小值和最大值。因此，`float` 值应当被当作对实数值的近似。这些近似只有有限的精度。把 `float` 值组合起来可能导致近似误差；如果不是因为近似，下面两个 expression 都会求值为 `7`。

```python
>>> 7 / 3 * 3
7.0
```

```python
>>> 1 / 3 * 7 * 3
6.999999999999999
```

尽管上面组合的都是 `int` 值，但用一个 `int` 除以另一个得到的却是一个 `float` 值：对两个整数相除所得的真实比值的一个被截断的有限近似。

```python
>>> type(1/3)
<class 'float'>
>>> 1/3
0.3333333333333333
```

当我们进行相等性测试时，这种近似带来的问题就会显现出来。

```python
>>> 1/3 == 0.333333333333333312345  # Beware of float approximation
True
```

`int` class 与 `float` class 之间的这些细微差异，对编写程序有着广泛的影响，因此它们是需要程序员记住的细节。幸运的是，原生数据类型只有寥寥几种，这就限制了熟练掌握一门编程语言所需的记忆量。而且，这些相同的细节在许多编程语言中都是一致的，由 [IEEE 754 浮点标准](http://en.wikipedia.org/wiki/IEEE_floating_point) 这样的社区准则来保证。

**非数值类型。** 值可以表示许多其他类型的数据，比如声音、图像、位置、网址、网络连接等等。其中少数由原生数据类型表示，比如表示值 `True` 和 `False` 的 `bool` class。大多数值的类型必须由程序员来定义，使用的方法就是我们在本章中将要发展的组合与 abstraction 手段。

接下来的几节将介绍更多 Python 原生数据类型，重点是它们在创建有用的 data abstraction 时所扮演的角色。如果你有兴趣了解更详细的内容，在线书籍 Dive Into Python 3 中关于 [原生数据类型](http://getpython3.com/diveintopython3/native-datatypes.html) 的一章给出了 Python 所有原生数据类型的实用概览以及如何操作它们，其中包含大量用法示例和实用技巧。
