# 2.6 实现 class 与 object

在使用面向对象编程范式时，我们用 object 这一隐喻来指导程序的组织。关于如何表示和操作数据的大部分逻辑，都写在 class 声明之中。在本节中我们将看到，class 和 object 本身也可以仅用 function 和 dict 来表示。以这种方式实现 object 系统，是为了说明使用 object 隐喻并不需要一门特殊的编程语言。即使是在没有内建 object 系统的编程语言里，程序也可以是面向对象的。

为了实现 object，我们将放弃 dot notation（它确实需要语言的内建支持），转而创建 dispatch dictionary，它们的行为与内建 object 系统的 element 大体相同。我们已经见过如何通过 dispatch dictionary 实现 message passing 行为。要完整地实现一个 object 系统，我们需要在 instance、class 和 base class 之间传递消息，它们全都是包含 attribute 的 dict。

我们不会实现完整的 Python object 系统，它包含本教材尚未涉及的特性（例如 meta-class 和 static method）。我们将专注于用户自定义的 class，不涉及 multiple inheritance，也不涉及 introspective 行为（例如返回某个 instance 所属的 class）。我们的实现并不打算遵循 Python 类型系统的精确规范，而是为了实现那些支撑 object 隐喻的核心功能。

## 2.6.1 instance

我们从 instance 开始。一个 instance 拥有具名 attribute，例如账户的 balance，这些 attribute 可以设置和取出。我们用一个 dispatch dictionary 来实现 instance，它响应“get”和“set”attribute 值的消息。attribute 本身存储在一个名为 `attributes` 的局部 dict 里。

正如本章前文所见，dict 本身就是一种 abstract data type。我们用 list 实现 dict，用 pair 实现 list，又用 function 实现 pair。当我们用 dict 来实现 object 系统时，请记住：我们也完全可以只用 function 来实现 object。

在开始实现之前，我们假设已经有一个 class 实现，它可以查找任何不属于该 instance 的名字。我们把一个 class 作为 parameter `cls` 传给 `make_instance`。

```python
>>> def make_instance(cls):
        """Return a new object instance, which is a dispatch dictionary."""
        def get_value(name):
            if name in attributes:
                return attributes[name]
            else:
                value = cls['get'](name)
                return bind_method(value, instance)
        def set_value(name, value):
            attributes[name] = value
        attributes = {}
        instance = {'get': get_value, 'set': set_value}
        return instance
```

`instance` 是一个 dispatch dictionary，它响应 `get` 和 `set` 消息。`set` 消息对应 Python object 系统中的 attribute 赋值：所有被赋值的 attribute 都直接存放在 object 本地的 attribute dict 里。在 `get` 中，如果 `name` 没有出现在本地的 `attributes` dict 里，就会到 class 中查找。如果 `cls` 返回的 `value` 是一个 function，就必须把它绑定到 instance 上。

**bound method 值。** `make_instance` 中的 `get_value` function 用 `get` 在它的 class 里找到具名 attribute，然后调用 `bind_method`。绑定 method 只对 function 值生效，它把一个 function 值变成 bound method 值，做法是把 instance 作为第一个 argument 插入：

```python
>>> def bind_method(value, instance):
        """Return a bound method if value is callable, or value otherwise."""
        if callable(value):
            def method(*args):
                return value(instance, *args)
            return method
        else:
            return value
```

当 method 被调用时，按照这个定义，第一个 parameter `self` 会被绑定到 `instance` 的值。

## 2.6.2 class

在 Python 的 object 系统和我们这里实现的系统中，class 本身也是一个 object。为简单起见，我们规定 class 自身没有 class。（在 Python 中，class 确实有 class；几乎所有 class 都共享同一个 class，名为 `type`。）一个 class 可以响应 `get` 和 `set` 消息，也可以响应 `new` 消息：

```python
>>> def make_class(attributes, base_class=None):
        """Return a new class, which is a dispatch dictionary."""
        def get_value(name):
            if name in attributes:
                return attributes[name]
            elif base_class is not None:
                return base_class['get'](name)
        def set_value(name, value):
            attributes[name] = value
        def new(*args):
            return init_instance(cls, *args)
        cls = {'get': get_value, 'set': set_value, 'new': new}
        return cls
```

与 instance 不同，class 的 `get` function 在找不到 attribute 时不会去查询自己的 class，而是去查询它的 `base_class`。class 不需要进行 method 绑定。

**初始化。** `make_class` 中的 `new` function 会调用 `init_instance`，后者先创建一个新 instance，然后调用名为 `__init__` 的 method。

```python
>>> def init_instance(cls, *args):
        """Return a new object with type cls, initialized with args."""
        instance = make_instance(cls)
        init = cls['get']('__init__')
        if init:
            init(instance, *args)
        return instance
```

这最后一个 function 使我们的 object 系统变得完整。现在我们有了 instance：`set` 时保存在本地，`get` 时则回退到它的 class。instance 在 class 中查到某个名字之后，会把自己绑定到 function 值上，从而创建 method。最后，class 可以 `new` 出 instance，并在 instance 创建之后立即应用它的 `__init__` constructor function。

在这个 object 系统中，唯一应该由用户调用的 function 是 `make_class`。其他所有功能都通过 message passing 来启用。类似地，Python 的 object 系统通过 `class` statement 来启动，其他所有功能都通过 dot expression 和对 class 的调用来启用。

## 2.6.3 使用已实现的 object

现在我们回到上一节的银行账户例子。使用自己实现的 object 系统，我们将创建一个 `Account` class、一个 `CheckingAccount` subclass，以及它们各自的一个 instance。

`Account` class 是通过 `make_account_class` function 创建的，它的结构与 Python 中的 `class` statement 类似，但以对 `make_class` 的一次调用结尾。

```python
>>> def make_account_class():
        """Return the Account class, which has deposit and withdraw methods."""
        interest = 0.02
        def __init__(self, account_holder):
            self['set']('holder', account_holder)
            self['set']('balance', 0)
        def deposit(self, amount):
            """Increase the account balance by amount and return the new balance."""
            new_balance = self['get']('balance') + amount
            self['set']('balance', new_balance)
            return self['get']('balance')
        def withdraw(self, amount):
            """Decrease the account balance by amount and return the new balance."""
            balance = self['get']('balance')
            if amount > balance:
                return 'Insufficient funds'
            self['set']('balance', balance - amount)
            return self['get']('balance')
        return make_class(locals())
```

最后对 `locals` 的一次调用会返回一个以 string 为键的 dict，其中包含当前 local frame 里的 name-value binding。

`Account` class 最终通过赋值完成实例化。

```python
>>> Account = make_account_class()
```

然后，通过 `new` 消息创建一个 account instance，这需要一个名字，与新创建的账户相配。

```python
>>> kirk_account = Account['new']('Kirk')
```

接着，传给 `kirk_account` 的 `get` 消息会取出 property 和 method。可以调用 method 来更新账户的 balance。

```python
>>> kirk_account['get']('holder')
'Kirk'
>>> kirk_account['get']('interest')
0.02
>>> kirk_account['get']('deposit')(20)
20
>>> kirk_account['get']('withdraw')(5)
15
```

与 Python 的 object 系统一样，设置 instance 的 attribute 不会改变它所属 class 的对应 attribute。

```python
>>> kirk_account['set']('interest', 0.04)
>>> Account['get']('interest')
0.02
```

**inheritance。** 我们可以通过重载 class attribute 的一个子集来创建 subclass `CheckingAccount`。在这个例子里，我们修改 `withdraw` method 来收取费用，并降低利率。

```python
>>> def make_checking_account_class():
        """Return the CheckingAccount class, which imposes a $1 withdrawal fee."""
        interest = 0.01
        withdraw_fee = 1
        def withdraw(self, amount):
            fee = self['get']('withdraw_fee')
            return Account['get']('withdraw')(self, amount + fee)
        return make_class(locals(), Account)
```

在这个实现中，我们从 subclass 的 `withdraw` function 里调用 base class `Account` 的 `withdraw` function，就像在 Python 内建的 object 系统中那样。和前面一样，我们可以创建这个 subclass 本身以及它的一个 instance。

```python
>>> CheckingAccount = make_checking_account_class()
>>> jack_acct = CheckingAccount['new']('Spock')
```

存款的行为完全相同，constructor function 也是如此。取款会按专门化的 `withdraw` method 收取 1 美元的费用，而 `interest` 则取 `CheckingAccount` 中新的较低值。

```python
>>> jack_acct['get']('interest')
0.01
>>> jack_acct['get']('deposit')(20)
20
>>> jack_acct['get']('withdraw')(5)
14
```

我们基于 dict 构建的这个 object 系统，在实现上与 Python 内建的 object 系统颇为相似。在 Python 中，任何用户自定义 class 的 instance 都有一个特殊的 attribute `__dict__`，它把该 object 的 local instance attribute 存放在一个 dict 里，和我们的 `attributes` dict 很像。Python 的不同之处在于，它会区分某些特殊的 method，这些 method 与内建 function 相互配合，确保这些 function 对许多不同类型的 argument 都能正确工作。作用在不同类型上的 function 是下一节的主题。
