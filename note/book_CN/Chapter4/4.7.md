# 4.7 分布式数据处理

分布式系统常常用于收集、访问和操作大规模的数据集。例如，本章前面介绍的数据库系统可以跨存储在多台机器上的数据集进行操作。任何单台机器都可能并不包含响应某个 query 所需的数据，因此需要通信来服务请求。

本节考察一个典型的大数据处理场景：数据集太大，无法由单台机器处理，于是被分散到许多机器上，每台机器处理数据集的一部分。处理结果往往需要在机器之间汇总，以便把一台机器计算的结果与其他机器的结果结合起来。为了协调这种分布式数据处理，我们将讨论一个名为 [MapReduce](http://en.wikipedia.org/wiki/MapReduce) 的编程框架。

用 MapReduce 创建分布式数据处理应用，综合了本教材通篇介绍的许多思想。一个应用用 pure function 来表达，这些 function 用来对大规模数据集执行 *map*，然后把 map 之后的值的 sequence *reduce* 成一个最终结果。

functional programming 中熟悉的概念在 MapReduce 程序中得到了最大程度的运用。MapReduce 要求用于 map 和 reduce 数据的 function 必须是 pure function。一般来说，只用 pure function 表达的程序在执行方式上有相当大的灵活性。sub-expression 可以按任意顺序并行计算，而不会影响最终结果。MapReduce 应用会并行 evaluate 许多 pure function，并重新安排计算的顺序，以便在分布式系统中高效执行。

MapReduce 的主要优势在于，它强制把分布式数据处理应用的两个部分之间的关注点分离开来：

1. 处理数据并合并结果的 map 和 reduce function。
2. 机器之间的通信与协调。

协调机制处理分布式计算中出现的许多问题，例如机器故障、网络故障和进度监控。虽然管理这些问题会给 MapReduce 应用带来一些复杂度，但这些复杂度都不会暴露给应用开发者。构建一个 MapReduce 应用只需指定上面第 (1) 项中的 map 和 reduce function；分布式计算的种种难题都通过 abstraction 隐藏了起来。

## 4.7.1 MapReduce

MapReduce 框架假定输入是大量、无序、类型任意的输入值 stream。例如，每个输入可以是某个庞大语料库中的一行文本。计算分三步进行。

1. 对每个输入应用一个 map function，它输出零个或多个任意类型的中间 key-value pair。
2. 所有中间 key-value pair 都按 key 分组，这样具有相同 key 的 pair 就能一起被 reduce。
3. 一个 reduce function 把给定 key `k` 对应的各个值合并起来；它输出零个或多个值，这些值在最终输出中都关联到 `k`。

为了执行这一计算，MapReduce 框架会创建若干 task（可能位于不同的机器上），它们在计算中扮演不同的角色。*map task* 对输入数据的某个子集应用 map function，并输出中间 key-value pair。*reduce* task 按 key 对 key-value pair 进行排序和分组，然后对每个 key 对应的各个值应用 reduce function。map task 与 reduce task 之间的所有通信都由框架处理，把中间 key-value pair 按 key 分组这件事也是如此。

为了在 MapReduce 应用中利用多台机器，多个 mapper 会在 *map phase* 中并行运行，多个 reducer 会在 *reduce phase* 中并行运行。在这两个 phase 之间，*sort phase* 通过排序把 key-value pair 分组，使所有具有相同 key 的 key-value pair 相邻。

考虑统计一个文本语料库中元音个数的问题。只要恰当选择 map 和 reduce function，我们就可以用 MapReduce 框架解决这个问题。map function 接受一行文本作为输入，输出若干 key-value pair，其中 key 是一个元音字母，value 是计数。计数为零的项不会出现在输出中：

```

def count_vowels(line):
    """A map function that counts the vowels in a line."""
    for vowel in 'aeiou':
        count = line.count(vowel)
        if count > 0:
            emit(vowel, count)
```

reduce function 就是 Python 内建的 sum function，它接受一个遍历各个值的 iterator（即某个给定 key 对应的所有值）作为输入，返回它们的和。

## 4.7.2 本地实现

要编写一个 MapReduce 应用，我们需要一个 MapReduce 框架的实现，以便把 map 和 reduce function 插进去。在下一节中，我们将使用开源的 [Hadoop](http://en.wikipedia.org/wiki/Hadoop) 实现。在本节中，我们用 Unix 操作系统的内建工具开发一个最简单的实现。

Unix 操作系统在用户程序与计算机底层硬件之间建立了一道 abstraction barrier。它提供了一种让程序相互通信的机制，特别是允许一个程序消费另一个程序的输出。在其关于 Unix 编程的开创性著作中，Kernigham 和 Pike 断言：“一个系统的威力，更多来自程序之间的关系，而不是程序本身。”

一个 Python 源文件只要在第一行加上一条注释，指明该程序应使用 Python 3 interpreter 来执行，就能变成 Unix 程序。Unix 程序的输入是一个 iterable object，称为*标准输入*，通过 `sys.stdin` 访问。对这个 object 进行遍历会得到以 string 为值的文本行。Unix 程序的输出称为*标准输出*，通过 `sys.stdout` 访问。内建的 `print` function 会把一行文本写入标准输出。下面这个 Unix 程序把输入的每一行反序写入输出：

```

#!/usr/bin/env python3

import sys

for line in sys.stdin:
    print(line.strip('\n')[::-1])
```

如果我们把这个程序保存到名为 `rev.py` 的文件中，就可以把它当作 Unix 程序来执行。首先，我们需要告诉操作系统，我们创建了一个可执行的程序：

```

$ chmod u+x rev.py
```

接下来，我们可以把输入传给这个程序。程序的输入可以来自另一个程序。这一效果通过 `|` 符号（称为“管道”）实现，它把管道之前那个程序的输出输送给管道之后的程序。`nslookup` 程序会输出某个 IP 地址对应的主机名（这里以《纽约时报》为例）：

```

$ nslookup 170.149.172.130 | ./rev.py
moc.semityn.www
```

`cat` 程序会输出文件的内容。因此，`rev.py` 程序可以用来把 `rev.py` 文件的内容反序：

```

$ cat rev.py | ./rev.py
3nohtyp vne/nib/rsu/!#

sys tropmi

:nidts.sys ni enil rof
)]1-::[)'n\'(pirts.enil(tnirp
```

这些工具足以让我们实现一个基本的 MapReduce 框架。这个版本只有一个 map task 和一个 reduce task，二者都是用 Python 实现的 Unix 程序。我们用下面这条命令运行整个 MapReduce 应用：

```

$ cat input | ./mapper.py | sort | ./reducer.py
```

`mapper.py` 和 `reducer.py` 程序必须实现 map function 和 reduce function，以及一些简单的输入输出行为。例如，为了实现上面描述的元音计数应用，我们会编写下面这个 `count_vowels_mapper.py` 程序：

```

#!/usr/bin/env python3

import sys
from mr import emit

def count_vowels(line):
    """A map function that counts the vowels in a line."""
    for vowel in 'aeiou':
        count = line.count(vowel)
        if count > 0:
            emit(vowel, count)

for line in sys.stdin:
    count_vowels(line)
```

此外，我们还会编写下面这个 `sum_reducer.py` 程序：

```

#!/usr/bin/env python3

import sys
from mr import values_by_key, emit

for key, value_iterator in values_by_key(sys.stdin):
    emit(key, sum(value_iterator))
```

[mr 模块](../examples/mapreduce/mr.py) 是本教材的配套模块，它提供了用于发出 key-value pair 的 function `emit`，以及用于把具有相同 key 的值分组的 `group_values_by_key`。这个模块还包含一个与 MapReduce 的 Hadoop 分布式实现对接的 interface。

最后，假设我们有下面这个名为 `haiku.txt` 的输入文件：

```

Google MapReduce
Is a Big Data framework
For batch processing
```

使用 Unix 管道在本地执行，就得到了这首俳句中每个元音的出现次数：

```

$ cat haiku.txt | ./count_vowels_mapper.py | sort | ./sum_reducer.py
'a'   6
'e'   5
'i'   2
'o'   5
'u'   1
```

## 4.7.3 分布式实现

[Hadoop](http://en.wikipedia.org/wiki/Hadoop) 是 MapReduce 框架的一个开源实现的名字，它在机器集群上执行 MapReduce 应用，把输入数据和计算分布开来以实现高效的并行处理。它的 streaming interface 允许用任意的 Unix 程序来定义 map 和 reduce function。事实上，我们的 `count_vowels_mapper.py` 和 `sum_reducer.py` 可以直接配合 Hadoop 安装，用来统计大型文本语料库中的元音。

与我们的简化版本地 MapReduce 实现相比，Hadoop 有几个优势。第一是速度：map 和 reduce function 通过在不同机器上同时运行的不同 task 并行应用。第二是容错：当某个 task 因任何原因失败时，它的结果可以由另一个 task 重新计算，以完成整体计算。第三是监控：框架提供了一个用户界面，用于跟踪 MapReduce 应用的进度。

要使用所提供的 `mapreduce.py` 模块运行元音计数应用，请安装 Hadoop，把 `HADOOP` 的赋值 statement 改为你本地安装的根目录，把一批文本文件复制到 Hadoop 分布式文件系统中，然后运行：

```

$ python3 mr.py run count_vowels_mapper.py sum_reducer.py [input] [output]
```

其中 `[input]` 和 `[output]` 是 Hadoop 文件系统中的目录。

关于 Hadoop streaming interface 以及该系统用法的更多信息，请查阅 [Hadoop Streaming 文档](http://hadoop.apache.org/docs/stable/streaming.html)。
