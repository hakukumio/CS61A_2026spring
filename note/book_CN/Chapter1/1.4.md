# 1.4 设计 Functions

> **Video:** [Watch on YouTube](https://www.youtube.com/watch?v=FzbVzGnVBB4)

Function 是一切程序的必备要素，无论程序是大是小；它们也是我们用编程语言表达计算过程的主要媒介。到目前为止，我们讨论了 function 的形式化性质以及它们如何被应用。现在我们转向另一个话题：什么样的 function 才称得上好。从根本上说，好的 function 的种种品质都强化了同一个观念——function 是 abstraction。

- 每个 function 都应当恰好承担一项职责。这项职责应当能用简短的名字标识，并能用一行文字描述。按顺序执行多项职责的 function 应当拆分成多个 function。
- *Don't repeat yourself* 是软件工程的一条核心准则。所谓的 DRY 原则指出，多个代码片段不应描述冗余的逻辑。相反，这段逻辑应当只实现一次，赋予一个名字，然后被多次应用。如果你发现自己正在复制粘贴一整块代码，那你很可能发现了一个使用 functional abstraction 的机会。
- Function 应当定义得足够通用。Python 库中之所以没有平方运算，正是因为它只是 `pow` function 的一个特例，而它可以把数字提升到任意次幂。

这些准则能提升代码的可读性，减少错误的数量，并且通常能最小化所写代码的总量。把复杂任务分解成简洁的 function 是一项需要经验才能掌握的技能。幸运的是，Python 提供了若干特性来支持你的努力。

## 1.4.1 文档

Function definition 通常会包含描述该 function 的文档，称为 *docstring*，它必须与 function body 一起缩进。按照惯例，docstring 用三引号括起来。第一行用一句话描述该 function 的职责。后面的若干行可以描述 argument，并阐明该 function 的行为：

```

>>> def pressure(v, t, n):
        """Compute the pressure in pascals of an ideal gas.

        Applies the ideal gas law: http://en.wikipedia.org/wiki/Ideal_gas_law

        v -- volume of gas, in cubic meters
        t -- absolute temperature in degrees kelvin
        n -- particles of gas
        """
        k = 1.38e-23  # Boltzmann's constant
        return n * k * t / v
```

把 function 的名字作为 argument 传给 `help` 时，你就会看到它的 docstring（输入 `q` 可以退出 Python help）。

```python
>>> help(pressure)
```

编写 Python 程序时，除了最简单的 function 之外，都应当写上 docstring。记住，代码只写一次，却常常要被阅读很多次。Python 文档中包含 [docstring 指南](http://www.python.org/dev/peps/pep-0257/)，它保证了不同 Python 项目之间的一致性。

**注释**。Python 中的注释可以写在 `#` 符号之后，附加在一行的末尾。例如上面那条注释 `Boltzmann's constant` 描述的就是 `k`。这些注释永远不会出现在 Python 的 `help` 中，interpreter 也会忽略它们。它们只为人类而存在。

## 1.4.2 默认 Argument 值

定义通用 function 的一个后果是需要引入额外的 argument。argument 很多的 function 调用起来很别扭，读起来也困难。

在 Python 中，我们可以为 function 的 argument 提供默认值。调用该 function 时，带有默认值的 argument 是可选的。如果没有提供这些 argument，那么默认值就会改而绑定到对应的 formal parameter 名字上。例如，如果某个应用经常要为 1 摩尔粒子计算压强，就可以把这个值作为默认值提供：

```

>>> def pressure(v, t, n=6.022e23):
        """Compute the pressure in pascals of an ideal gas.

        v -- volume of gas, in cubic meters
        t -- absolute temperature in degrees kelvin
        n -- particles of gas (default: one mole)
        """
        k = 1.38e-23  # Boltzmann's constant
        return n * k * t / v
```

在这个例子中，`=` 符号根据所处语境的不同，有两层不同的含义。在 `def` statement 的 header 中，`=` 并不执行赋值，而是指明调用 `pressure` function 时使用的默认值。相比之下，function body 中给 `k` 的 assignment statement 则把名字 `k` 绑定到 Boltzmann 常数的近似值上。

```python
>>> pressure(1, 273.15)
2269.974834
>>> pressure(1, 273.15, 3 * 6.022e23)
6809.924502
```

`pressure` function 定义为接受三个 argument，但上面的第一个 call expression 只提供了两个。在这种情况下，`n` 的值取自 `def` statement 的默认值。如果提供了第三个 argument，默认值就会被忽略。

作为一条准则，function body 中用到的多数数据值都应当表达为具名 argument 的默认值，这样它们便于查看，也便于 function 的调用者修改。有些永不改变的值，比如基本常数 `k`，则可以绑定在 function body 中或者 global frame 中。
