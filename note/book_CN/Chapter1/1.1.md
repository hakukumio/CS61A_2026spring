# 第 1 章：用 function 构建抽象

## 1.1 起步

计算机科学是一门极其宽广的学科。全球分布式系统、人工智能、机器人学、图形学、安全、科学计算、计算机体系结构，以及几十个新兴子领域，每年都在被新技术和新发现所拓展。计算机科学的飞速进步几乎没有让人类生活的任何方面不受影响。商业、通信、科学、艺术、休闲和政治都作为计算领域被重新发明了。

计算机科学之所以能有如此高的生产力，只是因为这门学科建立在一套优雅而强大的基本思想之上。一切计算都始于表示信息、规定处理信息的逻辑，以及设计抽象来管理这些逻辑的复杂性。要掌握这些基础，我们需要精确地理解计算机如何解释计算机程序并执行计算过程。

这些基本思想长期以来一直是通过经典教材 *Structure and Interpretation of Computer Programs*（[SICP](http://mitpress.mit.edu/sicp)）来教授的，其作者是 Harold Abelson 和 Gerald Jay Sussman，以及 Julie Sussman。本书大量借鉴了那本教材，原书作者慷慨地以 Creative Commons 许可授权了改编和重用。本书根据 [Creative Commons 署名-非商业性使用-相同方式共享许可协议第 3 版](http://creativecommons.org/licenses/by-nc-sa/3.0/deed.en_US) 发布。

Python 是一门广泛使用的编程语言，它从许多职业中招揽了爱好者：Web 程序员、游戏工程师、科学家、学者，甚至新编程语言的设计者。当你学习 Python 时，你就加入了一个百万之众的开发者社区。开发者社区是极其重要的机构：成员们互相帮助解决问题，分享自己的项目和经验，并共同开发软件和工具。尽职的成员常常因其贡献而获得名望和广泛的尊重。

Python 作为教学语言表现出色，因为在其整个历史中，Python 的开发者一直强调 Python 代码对人类而言的可解释性，并由 [Zen of Python](http://www.python.org/dev/peps/pep-0020/) 所倡导的优美、简洁和可读这几条指导原则加以强化。Python 特别适合本书，因为它广泛的功能集合支持多种不同的编程风格，我们将逐一探索。虽然在 Python 中编程没有唯一的方式，但开发者社区共享着一套约定，它们有助于阅读、理解和扩展已有的程序。Python 把极大的灵活性和易用性结合在一起，让学生能够探索许多编程范式，然后把新学到的知识应用到成千上万个[正在进行的项目](http://pypi.python.org/pypi)中。

本书在介绍 Python 特性的同时，也介绍抽象的技术和严格的计算模型，以此保持 [SICP](http://mitpress.mit.edu/sicp) 的精神。此外，本书还提供了 Python 编程的实用入门，包括一些高级语言特性和示例。随着你在本书中不断前进，你使用 Python 的熟练程度应当会自然而然地提高。

开始用 Python 编程的最好方式，是直接与 interpreter 交互。本节介绍如何安装 Python 3、如何与 interpreter 启动交互式会话，以及如何开始编程。

### 1.1.3 交互式会话

在交互式 Python 会话中，你在*提示符* `>>>` 之后输入一些 Python *代码*。Python *interpreter* 读取并执行你输入的内容，完成你的各种命令。

要启动交互式会话，运行 Python 3 应用程序。在终端提示符下输入 `python3`（Mac/Unix/Linux），或在 Windows 中打开 Python 3 应用程序。

如果你看到 Python 提示符 `>>>`，那么你已经成功启动了交互式会话。本书用提示符后跟一些输入来展示示例交互。

```python
>>> 2 + 2
4
```

**交互式控制。** 每个会话都保存着你输入内容的历史记录。要访问该历史，按 `<Control>-P`（上一条）和 `<Control>-N`（下一条）。`<Control>-D` 退出会话，并丢弃这份历史记录。在某些系统上，上下方向键也可以在历史记录中循环。

### 1.1.4 第一个示例

> 想象力把未知之物的形体
> 一一呈现，诗人的笔
> 又使它们成形，赋予虚无缥缈之物
> 一个居所和一个名字。
>
> —William Shakespeare, A Midsummer-Night's Dream

为了给 Python 一个像样的介绍，我们从一个使用了几种语言特性的例子开始。下一节我们将从零开始，逐块构建这门语言。不妨把本节看作即将登场特性的预告。

Python 内置支持许多常见的编程活动，例如处理文本、显示图形，以及在 Internet 上通信。这行 Python 代码

```python
>>> from urllib.request import urlopen
```

是一条 `import` statement，它加载了访问 Internet 上数据的功能。具体来说，它提供了一个名为 `urlopen` 的 function，该 function 可以访问统一资源定位符（URL）处的内容，URL 是 Internet 上某个东西的位置。

**Statements & Expressions**。Python 代码由 expression 和 statement 组成。广义而言，计算机程序由这样的指令组成，它们要么

1. 计算某个值
2. 执行某个动作

statement 通常描述动作。当 Python interpreter 执行一条 statement 时，它完成相应的动作。另一方面，expression 通常描述计算。当 Python 对一个 expression 求值时，它算出该 expression 的值。本章会介绍若干种 statement 和 expression。

赋值 statement

```python
>>> shakespeare = urlopen('http://composingprograms.com/shakespeare.txt')
```

把名字 `shakespeare` 与 `=` 后面那个 expression 的值关联起来。那个 expression 把 `urlopen` function 应用于一个 URL，该 URL 包含 William Shakespeare 37 部戏剧的完整文本，全部放在一个文本文档中。

**Functions**。Function 封装了操作数据的逻辑。`urlopen` 就是一个 function。网址是一份数据，Shakespeare 戏剧的文本是另一份。前者导出后者的过程可能很复杂，但我们只用一个简单的 expression 就能应用这个过程，因为那份复杂性被藏在了 function 内部。Function 是本章的首要主题。

另一条赋值 statement

```python
>>> words = set(shakespeare.read().decode().split())
```

把名字 `words` 关联到 Shakespeare 戏剧中出现的所有不同词所构成的 set，一共有 33,721 个。这条链中的命令 `read`、`decode` 和 `split` 各自作用于一个中间计算实体：我们 `read`（读取）从已打开的 URL 得到的数据，然后把数据 `decode`（解码）成文本，最后把文本 `split`（拆分）成词。所有这些词都被放进一个 `set` 中。

**Objects**。`set` 是一种 object，它支持集合运算，例如求交集和判断成员关系。object 无缝地把数据和操作数据的逻辑捆绑在一起，从而管理二者的复杂性。Object 是第 2 章的首要主题。最后，这个 expression

```python
>>> {w for w in words if len(w) == 6 and w[::-1] in words}
{'redder', 'drawer', 'reward', 'diaper', 'repaid'}
```

是一个复合 expression，它求值为所有这样一些 Shakespeare 词构成的 set：它们倒过来拼写后仍然是一个词。晦涩的记法 `w[::-1]` 逐个列举词中的字母，而 `-1` 表示倒着走。当你在交互式会话中输入一个 expression 时，Python 会在下一行打印它的值。

**Interpreters**。对复合 expression 求值需要一个精确的过程，以可预测的方式解释代码。实现这样一个过程、对复合 expression 求值的程序称为 interpreter。interpreter 的设计与实现是第 3 章的首要主题。

与其他计算机程序相比，编程语言的 interpreter 的独特之处在于它的通用性。Python 在设计时并没有考虑 Shakespeare。然而，它极大的灵活性使我们只用少数几条 statement 和 expression 就能处理大量文本。

最后我们会发现，所有这些核心概念都密切相关：function 就是 object，object 就是 function，而 interpreter 同时是二者的 instance。然而，清晰地理解这些概念以及它们在组织代码中的作用，对于掌握编程这门技艺至关重要。

### 1.1.5 错误

Python 在等待你的命令。我们鼓励你动手试验这门语言，即使你可能还不了解它完整的词汇和结构。不过，请做好遇到错误的准备。计算机虽然极其快速和灵活，但也极其死板。计算机的本性在 [Stanford 的入门课程](http://web.stanford.edu/class/cs101/code-1-introduction.html)中被描述为

> 计算机的基本方程式是：
>
> `computer = powerful + stupid`
>
> 计算机非常强大，能非常迅速地查看海量数据。计算机每秒可以执行数十亿次运算，而每次运算都相当简单。
>
> 计算机同时也愚笨和脆弱得惊人。它能做的运算极其死板、简单和机械。计算机缺少任何类似于真正洞察力的东西……它一点也不像电影里的 HAL 9000。至少，你不该把计算机当成某种大脑而惧怕它。归根结底，它是非常机械的。
>
> 编程就是一个人运用自己真正的洞察力，用计算机能做的这些微小、简单的小操作，构建出有用的东西。
>
> —Francisco Cai and Nick Parlante, Stanford CS101

当你用 Python interpreter 做实验时，计算机的死板就会立刻显现出来：即使是最细微的拼写和格式改动，也会导致意料之外的输出和错误。

学会解读错误、诊断意外错误的成因，称为*调试*。调试的一些指导原则是：

1. **增量测试**：每一个写得好的程序都由小的、模块化的组件构成，这些组件可以单独测试。尽早尝试你写的每一样东西，以便及早发现问题并对自己写的组件建立信心。
2. **隔离错误**：一条 statement 输出中的错误通常可以归因于某个特定的模块化组件。在试图诊断问题时，先把错误追踪到你能找到的最小代码片段，然后再尝试修正它。
3. **检查你的假设**：interpreter 确实会一字不差地执行你的指令——不多也不少。当某些代码的行为与程序员所相信（或假定）的行为不符时，它们的输出就会显得出乎意料。了解你的假设，然后把调试的精力集中在验证你的假设是否真的成立上。
4. **请教他人**：你并不孤单！如果你看不懂一条错误消息，去问朋友、老师或搜索引擎。如果你已经隔离出了错误，却想不出如何修正，请别人来看看。许多宝贵的编程知识都是在小组共同解决问题的过程中分享的。

增量测试、模块化设计、精确的假设和团队合作，是贯穿本书的主题。但愿它们也能贯穿你的计算机科学生涯。
