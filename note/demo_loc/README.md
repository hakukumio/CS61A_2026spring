# loc

统计一个目录下所有 .py 文件的行数。

- **做什么**:给一个目录,数出里面每个 .py 文件有多少行
- **输入**:一个目录路径,从命令行第一个参数来
- **输出**:每行一条 `<路径> <行数>`,按路径排序,最后一行 `TOTAL <总数>`,打到 stdout
- **怎么用**:`python3 loc.py <目录>`
- **什么算完成**:
  1. `bash check.sh` 输出 PASS
  2. 在 `data/sample` 上的输出与 `data/expected.txt` 逐字相同
  3. 给任意目录路径都不会崩溃

## 故意不做

- 不统计 .js / .md / .py 以外的任何后缀
- 不区分空行、注释行、代码行(全算)
- 不加颜色、不加进度条、不加 `--help`
- 不处理权限错误、不处理符号链接

这一节会随着项目推进而修改。现在写下来,是为了防止自己中途拐弯。
